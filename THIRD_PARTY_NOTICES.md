# Komponen pihak ketiga

Proyek memakai paket yang versinya dicatat pada package.json dan package-lock.json.

| Komponen | Penggunaan | Lisensi / sumber |
| --- | --- | --- |
| React dan React DOM | Antarmuka | MIT — https://react.dev/ |
| Vite dan plugin React | Pengembangan dan build | MIT — https://vite.dev/ |
| Lucide React | Ikon antarmuka | ISC — https://lucide.dev/license |
| Manrope | Font antarmuka | SIL Open Font License 1.1; lihat licenses/Manrope-OFL.txt. |
| Lora | Font judul | SIL Open Font License 1.1; lihat licenses/Lora-OFL.txt. |
| Silkscreen | Judul piksel pada Beranda | Copyright 2001 The Silkscreen Project Authors; SIL Open Font License 1.1. Berkas font dan lisensi utuh ada pada public/fonts/silkscreen/. Sumber: https://github.com/google/fonts/tree/main/ofl/silkscreen (diambil 22 Oktober 2026). |
| Vitest, ESLint, dan plugin terkait | Pemeriksaan pengembangan | Lisensi masing-masing paket tersedia setelah npm ci. |

Diagram entalpi dibuat sebagai SVG dalam kode. Data diagram adalah ilustrasi rancangan produk. Referensi konsep kimia dicantumkan di README.md, PRD, dan bagian sumber pada beranda. Tidak ada aset foto atau logo sekolah dari pihak lain.

Peta piksel pada Beranda dibuat sebagai SVG orisinal dalam `PixelJourneyScene.jsx`. Video referensi desain dari pengguna menjadi acuan gaya umum; gambar, kode, logo, nama produk, dan identitas pembuat dari video tidak disalin ke aplikasi.
